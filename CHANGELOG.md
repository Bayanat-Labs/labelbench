# Changelog

All notable changes to LabelBench are listed here. Versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-10-14

- First release archived on Zenodo, for a citable DOI.
- Added this changelog.
- No changes to the benchmark code, metrics or the v0.1 results.

## [0.1.0] - 2026-10-14

- First public release: the `labelbench` package and command, the v0.1 results,
  and the paper, figures and results files attached to the GitHub release.
- Published on PyPI as `bayanat-labelbench`.
